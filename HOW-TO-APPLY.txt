HOW TO APPLY v1.7.4
===================

FULL ZIP
1. Extract pancake-live-sales-monitor-v1.7.4.zip.
2. Open the extracted folder until api/, lib/, public/, package.json and vercel.json are directly visible.
3. GitHub -> CHUTIPONX/Live-view -> main -> Add file -> Upload files.
4. Ctrl+A the CONTENTS inside the extracted folder. Do NOT upload the ZIP itself.
5. Commit changes.
6. Wait for Vercel status Ready.
7. Open the dashboard and press Ctrl+Shift+R.

HOTFIX
Use Live-view-v1.7.4-hotfix.zip only if the repository is already on v1.7.3.
Extract it and upload every included file to the matching repository paths.

After deploy:
- Open Settings once. Each API card will show the Pancake account name if the /shops response exposes it; otherwise the configured API label is used.
- The dashboard LIVE ORDERS panel fills only when new orders pass exact reconciliation.
