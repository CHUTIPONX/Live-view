HOW TO APPLY v1.6.2

FULL ZIP
1. Extract pancake-live-sales-monitor-v1.6.2.zip.
2. Open the extracted folder until api/, lib/, public/, package.json and vercel.json are directly visible.
3. Select everything inside that folder.
4. GitHub Live-view -> Add file -> Upload files.
5. Upload all selected files and commit to main.
6. Wait for Vercel Ready.
7. Hard refresh with Ctrl+Shift+R.
