Pancake Live Sales v1.3.1

FIX: Vercel FUNCTION_INVOCATION_TIMEOUT

The live dashboard no longer asks one /api/sales invocation to fetch every shop.
It now creates one signed report plan with a fixed Bangkok cutoff, then fetches
small batches of 6 shops through separate Vercel invocations.

Rules preserved:
- Employee Statistic /analytics/sale only
- total = summary.price / 100 only
- all configured shops must complete before the displayed total changes
- a failed/timeout batch never becomes zero and never creates a fake +/-
- +/- compares complete snapshots only
- every shop in one cycle uses the same since/until cutoff

New API routes:
GET  /api/report-plan?kind=live|history
POST /api/report-batch
