Pancake Live Sales Monitor v1.7.5

ALL PAGE CONNECTION LIST

- Check All Pages now renders every discovered unique page, not only failed pages.
- Shows page name, Shop ID, API Account and live connection status.
- Search by page name / Shop ID / API account.
- Filters: All / Connected / Needs attention.
- Multiple API credentials for the same Shop ID are merged into one page row.
- Failed pages are sorted first.
- The list updates progressively while batched permission checks run.
- Honest discovery rule: a page that Pancake never returns to any configured API key cannot be named/listed by the monitor.

No sales-total, verified-order, sound, seasonal atmosphere, account-storage or security logic was changed.
