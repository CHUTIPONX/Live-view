Pancake Live Sales Monitor v1.2.9 — Vercel Setup

Vercel > Project > Settings > Environment Variables

APP_USER=Owner
APP_PASSWORD=<your password>
APP_SECRET=<long random secret, 32+ characters>

PANCAKE_POS_API_KEY_1=<your real Pancake POS API key>
PANCAKE_LABEL_1=Main Account
PANCAKE_SHOP_IDS_1=ALL

Optional:
PANCAKE_POS_API_KEY_2=...
PANCAKE_LABEL_2=Second Account
PANCAKE_SHOP_IDS_2=ALL
PANCAKE_POS_API_KEY_3=...
PANCAKE_LABEL_3=Third Account
PANCAKE_SHOP_IDS_3=ALL

Use ALL for automatic shop discovery, or comma-separated Shop IDs.

Do NOT set PANCAKE_MONEY_DIVISOR. v1.2.9 fixes the Employee Statistic raw money divisor at 100 in code.
After changing Environment Variables, redeploy.

v1.2.9 live source:
/shops/{SHOP_ID}/analytics/sale
split_by[]=User.id
summary.price / 100
