Pancake Live Sales Monitor v1.7.9

FIXES
1. New API accounts are no longer silently ignored when PANCAKE_CONNECTIONS_JSON also exists. JSON + PANCAKE_POS_API_KEY_N are merged and de-duplicated by key.
2. Vercel Private Blob + Environment accounts are merged, so an extra env API can contribute shops instead of being shadowed by older Blob config.
3. Large Pancake /shops directories are probed with pagination and de-duplicated.
4. Shop discovery cache reduced to 60 seconds.
5. Settings now shows per API: POS shop count, unique contribution, overlap, and scan pages.
6. Per-order popup/feed amount now prefers total_price_after_sub_discount. Main dashboard total remains authoritative Employee Statistic summary.price / 100.

IMPORTANT
- The Settings number is POS Shop count, not raw Facebook Page count. Pancake can attach/merge multiple Facebook Pages into one POS Shop.
- If a newly added API says +0 unique, every POS Shop it sees already exists under another API.
- Vercel Environment Variable changes require a new deployment before that deployment can read the new key.
